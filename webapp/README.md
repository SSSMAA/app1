# ISCHOOLGO - نظام إدارة المدرسة المتكامل

## 🎯 نظرة عامة

**ISCHOOLGO** هو نظام إدارة مدرسة متكامل مبني بتقنيات حديثة يوفر حلولاً شاملة لإدارة العمليات التعليمية والإدارية والمالية والتسويقية.

### ✨ الميزات الرئيسية

- **إدارة متعددة الأدوار**: 6 أدوار متخصصة (مدير عام، مدير تنفيذي، مسوق، مسؤول تدريب، وكيل عملاء، أستاذ)
- **لوحات قيادة تفاعلية**: مصممة خصيصاً لكل دور مع إحصائيات وتقارير في الوقت الفعلي
- **إدارة شاملة للطلاب**: من الزوار المحتملين إلى الطلاب المسجلين مع متابعة كاملة
- **نظام مدفوعات متقدم**: تتبع المدفوعات، التذكيرات، والتقارير المالية
- **إدارة الحملات التسويقية**: متابعة الحملات الإعلانية والعملاء المحتملين
- **نظام إدارة الأساتذة والمجموعات**: تنظيم الفصول والمناهج والجداول

## 📊 واجهات برمجة التطبيقات (APIs)

### إحصائيات النظام
- `GET /api/dashboard/stats` - إحصائيات عامة للنظام
- `GET /api/students` - قائمة الطلاب
- `GET /api/students/:id` - تفاصيل طالب محدد
- `POST /api/students` - إضافة طالب جديد

### إدارة الزوار
- `GET /api/visitors` - قائمة الزوار
- `POST /api/visitors` - إضافة زائر جديد

### إدارة المدفوعات
- `GET /api/payments` - قائمة المدفوعات
- `POST /api/payments` - تسجيل دفعة جديدة

### إدارة المجموعات والمستخدمين
- `GET /api/groups` - قائمة المجموعات
- `GET /api/groups?active=true` - المجموعات النشطة فقط
- `GET /api/users` - قائمة المستخدمين
- `GET /api/users?role=teacher` - المستخدمين حسب الدور

### التسويق
- `GET /api/leads` - العملاء المحتملون
- `POST /api/leads` - إضافة عميل محتمل
- `GET /api/campaigns` - الحملات الإعلانية

## 🗃️ هيكل قاعدة البيانات

### الجداول الرئيسية

#### 👥 المستخدمون (users)
- إدارة جميع مستخدمي النظام حسب الأدوار
- الأدوار: admin, director, marketer, head_trainer, agent, teacher

#### 🎓 الطلاب (students)
- بيانات الطلاب الكاملة مع معلومات الدفع والحالة
- ربط مع المجموعات والأساتذة

#### 👋 الزوار (visitors)
- الزوار المحتملين والحصص التجريبية
- تتبع مراحل التحويل من زائر إلى طالب

#### 💰 المدفوعات (payments)
- سجل شامل لجميع المدفوعات والإيصالات
- ربط مع الطلاب والوكلاء المسؤولين

#### 🏫 المجموعات (groups)
- تنظيم الفصول والمجموعات الدراسية
- ربط مع الأساتذة والجداول الزمنية

#### 📊 الحملات الإعلانية (campaigns)
- متابعة الحملات التسويقية وأدائها
- إحصائيات مفصلة عن التكلفة والعائد

#### 🎯 العملاء المحتملون (leads)
- إدارة العملاء المحتملين ومصادرهم
- تتبع حالات المتابعة والتحويل

## 🛠️ التقنيات المستخدمة

### Backend
- **Hono Framework** - إطار عمل سريع وخفيف للـ Edge Runtime
- **Cloudflare D1** - قاعدة بيانات SQLite موزعة عالمياً
- **TypeScript** - لضمان سلامة الكود وسهولة الصيانة

### Frontend
- **HTML5 & CSS3** - هيكل ونسق حديث
- **Tailwind CSS** - تصميم سريع ومرن
- **JavaScript (Vanilla)** - تفاعلية بدون تعقيدات
- **Chart.js** - رسوم بيانية تفاعلية
- **Font Awesome** - أيقونات احترافية

### البنية التحتية
- **Cloudflare Pages** - استضافة Edge مع أداء فائق
- **PM2** - إدارة العمليات والخدمات
- **Git** - إدارة الإصدارات

## 🔄 سير العمل

### للزوار الجدد
1. **استقبال الزائر** (Agent) → تسجيل البيانات الأساسية
2. **جدولة الحصة التجريبية** → تحديد التاريخ والوقت والأستاذ
3. **متابعة النتائج** → تقييم الحصة واتخاذ القرار
4. **التحويل للتسجيل** → إنشاء ملف طالب والدفع

### لإدارة الطلاب
1. **تسجيل الطالب** → إدخال البيانات وتحديد المجموعة
2. **متابعة المدفوعات** → تذكيرات ومتابعة الدفعات
3. **تسجيل الحضور** → متابعة حضور الحصص
4. **تقييم الأداء** → متابعة التقدم والنتائج

### للحملات التسويقية
1. **إنشاء الحملة** → تحديد المنصة والميزانية
2. **متابعة الأداء** → تتبع المشاهدات والنقرات
3. **تحليل العملاء المحتملين** → تقييم جودة الـ Leads
4. **تحسين الأداء** → تعديل الحملات حسب النتائج
